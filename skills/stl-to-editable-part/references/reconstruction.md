# 重建与排查

## 几何路线

- 先识别 STL 编码、面数、坐标范围和单位。焊接浮点重复点后确认每条无向边恰好由两张面共享且方向相反。输入有开边、非流形边、退化三角面或多个独立壳体时，先判断是否为损坏、预期多实体或其他拓扑。避免凭空补面或在容差内吞掉细节。
- 分面 STEP 只作为中间层。用 Open CASCADE 回读为 B-Rep，再用 `ShapeUpgrade_UnifySameDomain` 合并相邻共面的面与同线的边。保留孔口内环和真实折边。使用模型尺度允许的小容差，并以包围盒、面积或体积以及再次合并的结果检查意外改变。
- 从平面内环取独立顶点，在孔口平面上拟合圆。验证整周覆盖、圆拟合残差、两端的轴线和孔径，确认每个原孔壁恰好连接两端内环。把多边形内环换成解析圆并缝合整周解析圆柱面。轴线变化、开口直径不同或出现中间台阶时，先确定实际孔型，再选圆柱、圆锥或多段结构。
- 平面合并应维持原有体积。拟合圆柱代替内接多边形时，净体积通常略减。用孔径、孔深和旧孔的实际体积核对变化。若两端分面略有错位，不宜直接用平均端面面积乘长度作为精确旧孔体积。可在旧孔壁上做通量积分，垂直于轴的端盖对选定横向通量贡献为零。
- 其他方向的同类直通孔可先把孔轴转到 Y、重建后逆变换，重新核对世界坐标。具有多组孔轴或复杂曲面时，可逐组识别并按原有边界缝合，或在尺寸可靠时逆向建模。保留拟合依据与偏差。STL 仅保存离散外形，制造公差与设计特征历史需要其他来源。

## 本地依赖和目标软件

- 裸 `python` 不在 PATH 时，直接查找 `py` 或 Codex 工作区 Python。运行普通转换脚本前，实际执行一次 `import numpy; import OCP`，有可用环境就复用。已验证 Windows x64、Python 3.12 和 `cadquery-ocp-novtk==7.9.3.1.1`。若获准联网且需要安装，用 `python -m pip install --target <任务工作目录的依赖目录> cadquery-ocp-novtk==7.9.3.1.1 numpy`，已有 NumPy 时可省略它。
- 旧依赖目录列得出但导入报权限错，或网络明确受限时，停止反复尝试同一依赖路线。离线用 `probe_rounds.py` 或标准库的 `faceted_step.py` 先读取几何，然后复用能运行的本地 CAD 内核建模和回读。分面文件只用于源网格诊断和中转。避免在每次任务里重写 CAD 绑定或搜索整个磁盘。
- 原生 CAD 导入 STL 成为有效实体后，STEP 翻译器仍可能单独失败。一次有依据的兼容性排查后，可用独立 CAD 内核生成并回读 STEP。文件有效性与某台设备上的原生导入结果分别报告。
